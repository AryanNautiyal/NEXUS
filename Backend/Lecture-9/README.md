




***     Authentication              vs              Authorization ***

Authentication just means to verify if that person is that person whom he's logging in the account of 

So can say authentication is done to verify the user

Whereas Authorization means the power or control we have over a website or any document

Like we can read a document and cannot write on it as we don't have permission to do so 

Therefore similar is here authorization is used to check if the user has permission to perform the actions that he's currently trying to perform 


*** HTTP Status Code ***  [Important to send this with response]

Without it system might get corrupted

***         Code                        Meaning                                 When to Use     ***

            200                         OK                                      Successful GET/PUT/PATCH
            201                         Created                                 Resource created (POST)
            400                         Bad Request                             Invalid Client Input 
            401                         Unauthorized                            Authentication needed
            403                         Forbidden                               No Permission
            404                         Not Found                               Resource doesn't exist
            500                         Internal Server Error                   Server-side Failure
